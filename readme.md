## Task 3 – Data Visualisation

### Project Overview
Created visualisations using Python, Pandas, Matplotlib and Seaborn to understand employee data.

### Visualisations Created
1. Bar Chart – Average Salary by Education Level
2. Histogram – Employee Salary Distribution
3. Scatter Plot – Experience vs Salary
4. Line Chart – Average Salary by Experience
5. Box Plot – Salary Distribution by Gender
6. Pie Chart – Employees by Gender

### Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

### Key Learnings
- Created different types of data visualisations.
- Analysed employee salary distribution.
- Compared salary across education levels and genders.
- Explored the relationship between experience and salary.
- Saved charts as PNG files.

### Project Files
- `visualisations/task3_visualisations.ipynb`
- `visualisations/employees.csv`
- `reports/figures/`

### Conclusion
This project helped me understand employee data through visualisation and identify patterns and relationships in salary, education, experience and gender.
